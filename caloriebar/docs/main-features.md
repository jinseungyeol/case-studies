# 주요 기능

## 1. 홈쇼핑 신청 시스템 (다채널·차수제)

TV홈쇼핑 방송을 보고 들어온 시청자가 체험을 신청하는 시스템.

- **차수(round) 단위 운영** — 방송 회차별로 신청 데이터를 분리(단일 모델의 `round` 컬럼 + 복합 인덱스), 회차 마감·오픈을 뷰의 허용 리스트(`active_rounds`) 한 줄로 제어
- **다채널 확장** — 신청 모델에 `channel` 컬럼을 얹고 공용 폼 함수 하나를 채널별로 래핑하는 구조. 신규 채널 추가 시 마이그레이션·뷰·URL·매장 데이터를 더하되 신청 로직은 중복 없이 재사용. 확장 시점에 기존 신청 데이터를 디폴트 채널로 무손실 마이그레이션 ([troubleshooting](./troubleshooting.md))
- 신청 접수 → 신청자 매장 선택 → 지점 백오피스 노출 → 처리·전환(예약·방문·추가결제·환불) 상태 관리의 전 흐름

## 2. 지점 백오피스

- 계정 = 지점: 로그인하면 자기 지점 신청·예약만 조회
- 미확인 건수 사이드바 배지 상시 노출 — 별도 알림 시스템 없이 "할 일"이 보이는 UI
- 본사 계정은 전체 지점 조회 + 권역·통계·내보내기

## 3. 방문자 통계

- Django 미들웨어가 요청을 가로채 기록 — 페이지별 코드 수정 없음
- IP+시간 단위 유니크 제약으로 중복 제거 (새로고침 반복이 집계를 부풀리지 않음)
- 일별 추이·30일 평균을 관리자 페이지에서 확인

## 4. 권역 관리

- 지점 ↔ 권역 다대다 구조 + CRUD
- 권역별 예약 관리·지역 마케팅(특정 권역 대상 프로모션) 지원

## 5. 엑셀 다운로드

- 구매·신청 데이터를 관리자 권한별 필터링 적용해 내보내기
- 운영팀의 실제 워크플로(엑셀 후처리)에 맞춘 컬럼 구성
